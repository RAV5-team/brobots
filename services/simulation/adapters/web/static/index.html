Шаг «Симуляция»: проверка конфигурации из подбора

Демо-контур: интерфейс и сервис симуляции работают локально. Параметры задаются здесь, расчёт выполняется сервисом.

1. Конфигурация из подбора

Склад из датасета организатора · «Перемещение паллет» · 2000 паллет в сутки

Шаг «Подбор» выбрал решения и рассчитал для каждого состав парка. Выберите конфигурацию, которую проверяем в симуляции.

2. Переход к шагу симуляции

Что проверит симуляция

  • Вывозит ли эта конфигурация пиковый поток: не меньше потребности минус допуск (норматив 34, ±10 %).
  • Забираются ли паллеты в срок в каждый смоделированный день.
  • Выполняются ли все рейсы за сутки и хватает ли зарядных станций, чтобы роботы не разряжались.
  • Если не работает — что докупить. Если парк с запасом — можно ли меньше, сохранив запас на рост объёма.

Состав для проверки

По умолчанию — как в подборе. Можно изменить, например, чтобы показать ветку «докупить».
