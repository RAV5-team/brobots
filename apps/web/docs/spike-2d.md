# Спайк 2D-плеера (07a «Графики и 2D-сравнение», D-87)

**Вопрос.** Выдержит ли SVG + `requestAnimationFrame` два плеера с общим временем на ×1800 — не меньше 30 кадров/с на 1366×768? Если нет — Canvas 2D.

**Ответ: да, SVG с запасом.** 60 кадров/с без замедления, 59 кадров/с при замедлении CPU в 6 раз; критерий перестаёт выполняться между 10× и 20×. Canvas 2D не нужен.

> Спайк закрыт. Страница `/dev/spike-2d` (`src/pages/dev/spike2d/`) и скрипт `scripts/measureSpike2d.mjs` удалены 2026-09-28 — они есть в истории git до этой даты. Плеер экрана 07a меряет `npm run measure:player-07a` (раздел «Экран 07a» ниже).

## Что проверяли

- Страница `/dev/spike-2d` (`src/pages/dev/spike2d/`, удалена): два плеера — «Из подбора: 18/6» и «Рекомендация: 16/5», общее время, пуск и пауза, «В начало», скорости ×120 · ×600 · ×1800, перемотка по дню.
- Плеер (после экрана 07a — `src/components/charts/SimPlayer2D.tsx`, часы — `usePlaybackClock.ts` там же; спайк использует их же): SVG, схема склада рисуется один раз (259 узлов, 297 рёбер, 196 мест хранения), поверх — роботы кружками; позиции между кадрами трассы интерполируются (`positionsAt`). Время двигает `requestAnimationFrame` (`usePlaybackClock`), React перерисовывает только слой роботов.
- Трассы — настоящий движок `services/simulation` (`simcore.viz.export_trace`), формат ответа `GET /api/simulations/{id}/traces`: `npm run gen:traces` (Docker, Python 3.12). Вход — демо-вход сервиса (РЦ Химки: 1 000 + 1 000 паллет, пик 1,5, две смены по 11 ч), seed сервиса; 5 521 кадр с шагом 15 с на плеер (23 ч), 18 и 16 роботов. Трассы синтетические, не из PRD (README фикстур).

## Что это значит для экрана 07a

- Плеер 07a — SVG, как в спайке; Canvas 2D не нужен.
- Трассы грузятся отдельными чанками по требованию (≈150 КБ gzip каждая), в основной бандл не входят.
- Для экрана: ползунок времени — примитив `Slider` (утверждён только для плеера), вместо нативного `input[type=range]` спайка; подписи состояний — словарь, цвета — тона графиков (`chartTones`), не цвета сервиса `state_colors`.
- Формат трасс в `openapi.json` не описан — тип и проверка написаны вручную по `export_trace` (`src/api/mappers/trace.ts`); вопрос бэкенду — `docs/api-contract.md`, №6.
- На 08:00 в трассе заняты 2 робота из 18 — так движок моделирует начало смены. Для экрана это данные сервиса; сверять с почасовыми рядами фикстур (синтетическими) не нужно.
