# Журнал дизайн-решений

Решения, принятые разработкой вместо дизайнера, и расхождения макетов с PRD.
Статусы: `open` — нужен ответ команды; `proposed` — рабочее решение, можно делать; `accepted` — подтверждено PRD или командой; `closed` — вопрос снят.
