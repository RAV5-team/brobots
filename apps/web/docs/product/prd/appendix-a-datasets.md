# Приложение А. Датасеты объектов

Все 138 параметров из файла Датасеты_хакатон.xlsx без изменений: единица, базовое значение, допустимый диапазон и примечание организатора. Базовое значение идёт в демо-данные и значение по умолчанию, диапазон — в валидацию, примечание — в подсказку и источник норматива \[ДС-Легенда, ТЗ 3.2.4, 3.2.5\].
