## Как устроена копия

- Каждый файл начинается с заголовка раздела (`#`); подразделы — `##`, их части — `###`.
- Колонтитулы, титульная страница и оглавление docx не переносятся; паспорт документа — таблица выше.
- Текст, таблицы и метки источников (`[ТЗ 3.4.2]`, `[Флоу 3.4]`, `[Экран А2]`) — без изменений.

## Как пересобрать

В docx стили заголовков называются `Heading N`, и pandoc 3.6 их не распознаёт: весь текст выходит абзацами. Поэтому перед конвертацией абзацам со стилем `Heading1–4` в `word/document.xml` ставится текстовый маркер уровня, а после конвертации маркеры заменяются на `#`:

1. Распаковать docx, в начало каждого абзаца `Heading1–4` вставить маркер уровня, упаковать обратно.
2. `pandoc <docx> -t gfm --wrap=none --extract-media=<dir>`.
3. Разрезать результат по заголовкам уровня 2 («Как читать документ», разделы 1–15) и уровня 1 («Приложение А/Б»); заголовки «Часть I–III» и всё до «Как читать документ» (титул и оглавление) отбросить; уровни заголовков сдвинуть так, чтобы раздел стал `#`.
4. Картинки перенести в `media/`; четыре файла без расширения переименовать: `03-4-matching-logic.png`, `05-sections-map.png`, `06-1-catalog-paths.png`, `06-4-excel-upload.png`.
5. Обновить таблицы «Разделы» и «Что изменилось» в этом README.
