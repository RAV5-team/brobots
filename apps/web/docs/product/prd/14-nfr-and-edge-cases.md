# 14. Нефункциональные требования и граничные случаи

RAV5 — веб-приложение с раздельными клиентской и серверной частями. Оно запускается в Docker и на демонстрации работает на заранее загруженных данных \[ТЗ 4.2.1, 4.2.3, 4.2.7\].

| **Область** | **Требование** | **Источник** |
|----|----|----|
| Оборудование | Стандартный ПК или ноутбук, современный веб-браузер | \[ТЗ 4.1.1\] |
| Оборудование | Специальное оборудование и графические ускорители у пользователя не нужны | \[ТЗ 4.1.2\] |
| Оборудование | Сервер разворачивается на компьютере команды или в облаке, доступном для демонстрации | \[ТЗ 4.1.3\] |
| Архитектура | Веб-приложение с разделением клиента и сервера | \[ТЗ 4.2.1\] |
| Архитектура | Любой обоснованный стек; предпочтительно свободное ПО с открытым кодом | \[ТЗ 4.2.2\] |
| Архитектура | Компоненты запускаются в контейнерах Docker; есть Dockerfile и docker-compose.yml либо эквивалентная воспроизводимая конфигурация | \[ТЗ 4.2.3\] |
| Архитектура | Реляционная или документо-ориентированная СУБД | \[ТЗ 4.2.4\] |
| Архитектура | Взаимодействие компонентов документировано; для API рекомендуется OpenAPI | \[ТЗ 4.2.5\] |
| Архитектура | Можно добавлять отрасли, объекты, параметры, решения и расчётные модули | \[ТЗ 4.2.6\] |
| Архитектура | Внешние источники — не единственная точка отказа; конкурсная версия работает на предзагруженных данных | \[ТЗ 4.2.7\] |
| Производительность | Каталог, формы и сохранённые проекты открываются без заметных задержек при нагрузке до 50 одновременных пользователей | \[ТЗ 4.3.1\] |
| Производительность | Расчёт экономики типового проекта — до 10 секунд | \[ТЗ 4.3.2\] |
| Производительность | Запуск или пересчёт модели — до 60 секунд, со статусом выполнения | \[ТЗ 4.3.3\] |
| Производительность | Ошибки загрузки данных обрабатываются корректно, сохранённый проект не теряется | \[ТЗ 4.3.4\] |
| Безопасность | Доступ разграничен по ролям | \[ТЗ 4.4.1\] |
| Безопасность | Пароли не хранятся в открытом виде | \[ТЗ 4.4.2\] |
| Безопасность | Проекты разных пользователей изолированы | \[ТЗ 4.4.3\] |
| Безопасность | При размещении в сети — защищённый протокол | \[ТЗ 4.4.4\] |
| Безопасность | В демо-наборе нет реальных персональных данных и сведений ограниченного доступа | \[ТЗ 4.4.5\] |
| Безопасность | Проект удаляется вместе со связанными загруженными файлами | \[ТЗ 4.4.6\] |
| Интерфейс | Русскоязычный, последовательный, понятный без знаний программирования | \[ТЗ 4.5.1\] |
| Интерфейс | Ключевой сценарий от выбора объекта до расчёта проходится без инструкции | \[ТЗ 4.5.2\] |
| Интерфейс | В полях есть единицы измерения, подсказки и примеры значений | \[ТЗ 4.5.3\] |
| Интерфейс | Ошибки и ограничения написаны понятным языком и содержат способ исправления | \[ТЗ 4.5.4\] |
| Интерфейс | Корректная работа при разрешении от 1366×768 | \[ТЗ 4.5.5\] |

**Граничные случаи, прямо названные в документах**

| **Ситуация** | **Что требуется** | **Источник** |
|----|----|----|
| Значение вне допустимого диапазона | Подсветка значения и сообщение со способом исправления | \[ДС-Легенда шаг 3, ТЗ 3.2.4, 4.5.4\] |
| Пустое обязательное поле, неверный тип или единица | Проверка при вводе и при загрузке файла | \[ТЗ 3.2.4\] |
| Ошибка при загрузке файла | Корректная обработка; ранее сохранённый проект не теряется | \[ТЗ 4.3.4\] |
| По решению не хватает данных | Решение помечается как требующее проверки | \[ТЗ 3.4.3\] |
| Нарушено ключевое ограничение | Решение не рекомендуется | \[ТЗ 3.4.3\] |
| Пользователь добавляет решение вне подборки | Разрешить и показать предупреждение | \[ТЗ 3.4.4\] |
| У решения нет обязательной ТТХ | Явное допущение и границы применимости решения | \[Доп. 4\] |
| Годовой эффект нулевой или отрицательный | Формула окупаемости ТЗ действует только при положительном эффекте; что показывать — решает команда | \[ТЗ 3.5.2\] |
| Пользователь вручную правит рассчитанное значение | Изменение фиксируется | \[ТЗ 3.5.4\] |
| Дубли позиций в файле цен | Считать альтернативными предложениями; выбранный вариант обозначить явно | \[Доп. 6\] |
| Недоступен внешний источник данных | Демонстрация продолжает работать на предзагруженных данных | \[ТЗ 4.2.7\] |
| Долгий пересчёт модели | Пользователь видит статус выполнения | \[ТЗ 4.3.3\] |
| Расчёт гостя | Коммерчески чувствительные данные не сохраняются | \[ТЗ 3.1.2\] |
| Удаление проекта | Удаляются и связанные загруженные файлы | \[ТЗ 4.4.6\] |

Пустые состояния и ошибки валидации

Пустые состояния отрисованы в Figma для процессов, локаций, процессов локации и дашборда. Текст ошибки у поля есть в одном месте — площадь активной зоны на форме локации. Остальные тексты ниже — предложение по ТЗ: ошибки «сформулированы понятным языком и содержат способ исправления» \[ТЗ 4.5.4\].

| **Где** | **Состояние** | **Текст на экране** | **Источник** |
|----|----|----|----|
| **Список проектов** | Нет проектов | Предложение: «Проектов пока нет. Выберите локацию и процесс» + «Новый проект» | \[ТЗ 4.5.1\] |
| **Процессы** | Нет процессов | «Процессов пока нет · Создайте первый шаблон процесса — потом добавите его в любую локацию» + «Создать процесс» \[Экран «Процессы · список · пусто»\] | \[ТЗ 4.5.1\] |
| **Процессы локации** | На локации нет процессов | «На этой локации ещё нет процессов · Добавьте процесс из раздела „Процессы“ — он станет отдельным экземпляром этой локации» + «Добавить процесс» \[Экран «Локации · процессы · пусто»\] | \[ТЗ 4.5.1\] |
| **Дашборд** | Нет проектов | Счётчики 0 и «Проектов пока нет · Начните с процессов и локаций: создайте процесс, добавьте его в локацию — и посчитайте проект» + «Новый проект» \[Экран «Дашборд · пусто»\] | \[ТЗ 4.5.1\] |
| **Шаг 1 проекта** | Не хватает критичного значения | «Не хватает данных: частота пересчёта. Технический подбор недоступен, пока значение не заполнено в профиле» \[Прототип\] | \[ТЗ 3.2.4, 4.5.4\] |
| **Список локаций** | Нет локаций | «Локаций пока нет · Создайте локацию — потом добавите в неё процессы и посчитаете роботизацию» + «Создать новую локацию» \[Экран «Локации · список · пусто»\] | \[ТЗ 2.2 шаг 1\] |
| **Подбор** | Нет кандидатов после фильтров | «Ни одно решение не прошло условия процесса. Ослабьте условие (кнопка «Изменить условия») или добавьте решение вручную из исключённых» | \[ТЗ 3.4.3, 3.4.4\] |
| **Поле формы** | Значение вне диапазона | «Ширина прохода 0,4 м — вне диапазона 1–6 м. Укажите ширину самого узкого проезда, по которому пойдёт робот» | \[ТЗ 3.2.4, 4.5.4, ДС-Легенда\] |
| **Поле формы** | Не та единица | «Ожидается м², введено м. Площадь указывается в квадратных метрах» | \[ТЗ 3.2.4, 4.5.3\] |
| **Поле формы** | Пустое обязательное | «Поле обязательное: без режима работы не посчитать пиковый поток» | \[ТЗ 3.2.4\] |
| **Загрузка файла** | Файл не прочитан | «Файл не прочитан: ожидается xlsx или csv по шаблону. Скачайте шаблон и заполните лист „Локация“». Сохранённые данные не тронуты | \[ТЗ 4.3.4\] |
| **Экономика** | Эффект нулевой или отрицательный | В рейтинге подпись «Чистый эффект отрицательный», окупаемость «не окупается»; на итоге вывод «Не рекомендуется при текущих условиях» и «Годовой денежный эффект …: новые расходы превышают экономию» \[Прототип\] | \[ТЗ 3.5.2, 3.5.7\] |
| **Симуляция** | Прогон дольше 60 с | «Симуляция выполняется · N с» с журналом прогона; вердикт «Не достигается · Не хватает даже большого парка», если нужно больше 60 роботов \[Прототип\] | \[ТЗ 4.3.3\] |
| **Внешний источник** | Источник недоступен при обновлении каталога | «Источник не ответил. Каталог остался на версии v4 от 15.09.2026» | \[ТЗ 4.2.7\] |

Ошибка у поля показывается под полем красным текстом и повторяется в панели готовности справа со ссылкой на поле; форма сохраняет черновик даже с ошибками, но кнопка «Сохранить» подписана «Исправьте N ошибок» \[Экран 14, панель готовности\].
