# Как читать документ

RAV5 — веб-платформа предынвестиционной оценки роботизации. Документ описывает продукт целиком: от наполнения каталога администратором до сохранённого проекта с расчётом. Требования и данные взяты из документов организатора хакатона ФЦ БАС. У каждого утверждения есть ссылка на источник.

**Метки статуса в таблицах**

| **Метка**   | **Что значит**                                    |
|-------------|---------------------------------------------------|
| ТЗ          | Требование организатора, обязательно к выполнению |
| Макет       | Так сделано на экране RAV5, описано по скрину     |
| Решение     | Решение команды, принятое при подготовке PRD      |
| Предложение | Предложение в PRD, требует подтверждения команды  |

Статусы данных на экранах

На экранах сейчас три набора статусов значений: на шаге 1, в карточке решения и на итоге. Предложение — один словарь для всего продукта. Слева статус, справа — какие подписи экранов он заменяет \[Прототип\].

| **Статус** | **Что значит** | **Сейчас на экранах** |
|----|----|----|
| **подтверждено** | Есть документальный источник: паспорт, каталог, профиль с подтверждением | подтверждено · факт · цена прайса · Технический паспорт |
| **указано** | Ввёл пользователь в профиле локации или процесса | указано |
| **из файла** | Загружено из Excel или датасета | из файла · датасет |
| **из локации** | Унаследовано из профиля локации | из локации · Профиль локации · Бюджет локации |
| **рассчитано** | Получено формулой из других значений | рассчитано · предварительно · расчёт · оценка (для расчётных) |
| **по аналогу** | Взято у решения того же класса | по аналогу · допущение · аналог того же класса |
| **допущение** | Норматив или решение команды; видно основание | допущение · оценка · Оценка команды · норматив модели |
| **нет данных** | Значения нет; расчёт идёт, зависящее решение — «требует проверки» | нет данных · не проверено · ещё не проверено |
| **не применяется** | К этому процессу или сценарию не относится | не применяется |
