# Фикстуры демо-данных

Данные для сервисов-моков (`apps/web/src/services/mock`) до подключения `services/api`. Правило D-13: единые фикстуры, приоритет значений — датасет и файлы организатора → справочники администратора (А5, А8) → формы макетов. Производные значения (счётчики, суммы) не хранятся, а считаются.

Числа роботов по классу (А8, 07, 11: «36 роботов», «46», разбивка 24 / 10 / 2) не переносятся: в фикстурах 20 демо-роботов, счётчики считаются из них (`countRobotsByClass`; на экране 11 — 16 роботов OP-01, 3 / 5 / 8 по подтверждённости ТТХ).
